# SauceDemo E2E Tests

Automated end-to-end tests for [saucedemo.com](https://www.saucedemo.com) built with Python, Playwright, and pytest.

## Tech stack

- Python 3.13
- Playwright
- pytest

## Setup

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
playwright install
```

## Running tests

```bash
pytest
```

Test automation portfolio project. Manual QA background (8+ years), building automation skills with Python and Playwright.
